# Password Manager GUI

A desktop Password Manager built with Python and **Tkinter**, created as part of Dr. Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp* (Days 29 & 30).

## Features
- **Strong Password Generator:** Generates randomized, secure passwords combining letters, numbers, and symbols, and automatically copies them to the clipboard using `pyperclip`.
- **Save Credentials Locally:** Stores website, email/username, and password entries in a structured `JSON` file (`data.json`).
- **Instant Search:** Look up saved credentials by website name with error handling for missing entries or empty databases.
- **Input Validation:** Alerts the user with pop-up dialogs if required fields are left blank before saving.

## Built With
- **Python 3**
- **Tkinter** (Standard Python GUI library)
- **Pyperclip** (Cross-platform clipboard copy/paste)
- **JSON** (Local data persistence & exception handling)
